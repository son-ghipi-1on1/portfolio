# Portfolio

[Start Bootstrap - Freelancer](https://startbootstrap.com/theme/freelancer) テーマをベースにした、個人ポートフォリオサイトです。

## 特徴

- HTML / CSS / JavaScript のみで構築された静的サイト(ビルド不要)
- Bootstrap をベースにしたレスポンシブデザイン
- 作品紹介(Portfolio)、自己紹介(About)、お問い合わせ(Contact)の各セクションを収録

## ディレクトリ構成

```
.
├── index.html              # サイト本体(HTML)
├── css/
│   └── styles.css          # スタイルシート
├── js/
│   └── scripts.js          # スクリプト
├── assets/
│   ├── favicon.ico         # ファビコン
│   └── img/
│       ├── avataaars.svg   # プロフィール画像
│       └── portfolio/      # 作品画像
└── .circleci/
    └── config.yml          # CircleCI の設定
```

## ローカルでの確認方法

ビルド不要の静的サイトなので、`index.html` をブラウザで直接開くだけで確認できます。

VS Code の [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) 拡張機能などを使うと、変更をリアルタイムに反映しながら確認できて便利です。

## カスタマイズ方法

- **テキスト・画像**: [index.html](index.html) 内の名前・肩書き・自己紹介文・作品画像などを編集してください
- **配色・レイアウト**: [css/styles.css](css/styles.css) を編集してください
- **動作(モーダル表示など)**: [js/scripts.js](js/scripts.js) を編集してください
